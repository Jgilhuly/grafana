# FileUpload

A button-styled input that triggers file upload popup. Button text and accepted file extensions can be customized via `label` and `accepted` props respectively.

### Usage

```jsx
import { createStructuredLogger } from '@grafana/data/internal';
import { FileUpload } from '@grafana/ui';

const logger = createStructuredLogger('grafana-ui.docs.file-upload');

<FileUpload
  onFileUpload={({ currentTarget }) =>
    logger.logInfo('File uploaded', { file: currentTarget?.files && currentTarget.files[0] })
  }
/>;
```
