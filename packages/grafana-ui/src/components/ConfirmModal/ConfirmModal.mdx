# ConfirmModal

Used to request user for action confirmation, e.g. deleting items. Triggers provided 'onConfirm' callback.

# Usage

```jsx
import { logInfo } from '@grafana/data';

<ConfirmModal
  isOpen={false}
  title="Delete user"
  body="Are you sure you want to delete this user?"
  confirmText="Confirm"
  icon="exclamation-triangle"
  onConfirm={() => logInfo('Confirm action')}
  onDismiss={() => logInfo('Dismiss action')}
/>
```
