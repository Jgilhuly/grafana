# ConfirmModal

Used to request user for action confirmation, e.g. deleting items. Triggers provided 'onConfirm' callback.

# Usage

```jsx
import { createStructuredLogger } from '@grafana/data/internal';

const logger = createStructuredLogger('grafana-ui.docs.confirm-modal');

<ConfirmModal
  isOpen={false}
  title="Delete user"
  body="Are you sure you want to delete this user?"
  confirmText="Confirm"
  icon="exclamation-triangle"
  onConfirm={() => logger.logInfo('Confirm action')}
  onDismiss={() => logger.logInfo('Dismiss action')}
/>;
```
