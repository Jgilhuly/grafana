# FilterPill

A component used for quick toggling on/off filters. Mostly used in inline form components and transformation/query editors.

### Usage

```jsx
import { createStructuredLogger } from '@grafana/data/internal';
import { FilterPill } from '@grafana/ui';

const logger = createStructuredLogger('grafana-ui.docs.filter-pill');

<FilterPill label={'Test'} onClick={() => logger.logInfo('Filter pill toggled')} />;
```
