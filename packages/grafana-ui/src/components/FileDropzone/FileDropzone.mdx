# FileDropzone

A dropzone component to use for file uploads.

### Usage

```jsx
import { FileDropzone } from '@grafana/ui';

<FileDropzone
  onLoad={(result) => console.info(JSON.stringify({ level: 'info', message: 'File dropzone loaded', context: { result } }))}
/>;
```
