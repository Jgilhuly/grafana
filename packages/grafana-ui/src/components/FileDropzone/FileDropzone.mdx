# FileDropzone

A dropzone component to use for file uploads.

### Usage

```jsx
import { createStructuredLogger } from '@grafana/data/internal';
import { FileDropzone } from '@grafana/ui';

const logger = createStructuredLogger('grafana-ui.docs.file-dropzone');

<FileDropzone onLoad={(result) => logger.logInfo('File loaded', { result })} />;
```
