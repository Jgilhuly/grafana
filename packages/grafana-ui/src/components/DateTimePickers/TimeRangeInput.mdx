# TimeRangeInput

A variant of `TimeRangePicker` for use in forms.

`dateTime(null)` can be used to provide empty time range value. The shape of the return value on input clear is:

```javascript
{
  from: dateTime(null),
  to: dateTime(null),
  raw: {
    from: dateTime(null),
    to: dateTime(null),
  },
};
```

`dateMath.isValid()` from `@grafana/data` can be used to check for a valid time range value.

### Usage

```jsx
import { createStructuredLogger } from '@grafana/data/internal';
import { TimeRangeInput } from '@grafana/ui';

const logger = createStructuredLogger('grafana-ui.docs.time-range-input');

<TimeRangeInput
  value={timeRange}
  onChange={(range) => logger.logInfo('Time range changed', { range })}
  onChangeTimeZone={(tz) => logger.logInfo('Time zone changed', { timeZone: tz })}
/>;
```
